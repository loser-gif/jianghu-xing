## 交付范围

- 案件与试炼共用自动战斗决策，均衡 / 进攻 / 稳守、1 / 2 / 4倍速、暂停 / 继续 / 撤离。自动用药默认关闭，策略与速度随存档保存。每回合持久化，非首回合刷新恢复后先暂停。胜利不会连闯下一层。
- 百业生活提供药师、铁匠、渔者，分别采药炼药、采矿锻造、垂钓烹饪；有职业熟练等级、地点和配方条件、每日订单、出售余料、补给使用和初次操作指引。
- 一年360日，一日6时段，每段两时辰。保留既有时间刻度，案件48时段仍为8日。时间只随行动推进；离线或查看页面不增龄。
- 新角色17岁入世；旧档以迁移时刻作为17岁基点，不追扣历史寿命。基础80岁，境界寿元上限逐步提高至太朴1000岁。
- 闭关1 / 7 / 30 / 360日，显示修为、日期、年龄与余寿预览，二次确认；计时案件期间禁用。寿尽时不发放未完成行动的收益，保留存档进入只读人生结算；可回看、管理/导出存档与返回主菜单。
