# 朝廷案牍验收 · 2026-10-09

## 功能与规则

资深捕快接《漕运失银》，结案及达到七品、声望60、贡献100后可升总捕；总捕接《伪诏私征》，结案及达到五品、声望110、贡献180后可升锦衣卫；锦衣卫接《江南密函》。原烟雨楼盗案与捕快入职保留。

每案两处取证，可任意顺序完成；限期48时段，抵达最后时段取证也按超时处理。进入交锋后不再因调查限期超时。结案需返回官府，选择预览后发放一次奖励；战斗胜利不提前奖励。撤案、战败与超时次日可重接，不重置属性或装备。寿尽保留人生档案并结束进行中的案卷。

俸银按游戏日领取，晋升不刷新当日领取。案件期间禁止闭关、试炼和宗门事务。旧档缺失 court 字段时自动迁移，非法案件ID、证据、阶段或战斗状态拒绝导入。

## 真实浏览器验收

通过本地5176预览与正式存档导入界面操作；未改写浏览器内部状态。测试专用旧格式存档起点为五品、资深捕快，已结烟雨楼盗案，声望25、贡献40、银两2000，用于集中验证新案链；不是声称从全新角色走完所有前置。

1. 导入缺失案牍字段的旧档正常；领取16两俸银后按钮禁用。
2. 漕运失银：旧码头与客栈取证，自动战斗暂停、1/4倍速切换；第二回合刷新后继续存档，双方气血和回合保留，战斗等待手动恢复。获胜回府选拨银救助，赏银180两，晋升总捕。
3. 伪诏私征：先官府、后铁匠铺取证，后巷自动战斗，回府依律归档获360两，晋升锦衣卫。
4. 江南密函：烟雨楼和旧码头取证，低于推荐境界一阶挑战，开启自动用药后获胜；回府依律归档获500两。最终银两3056、声望170、贡献280，新案完成3/3，三张案卡均显示已结案及历史选择。
5. 320×740、390px手机与1100×900桌面检查，无横向溢出；共享宣纸、水墨、官印视觉样式。最后浏览器控制台无错误或警告。测试后恢复默认视口。
