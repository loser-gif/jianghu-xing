# 江湖行

手机竖屏优先的文字武侠 RPG。首个可玩篇章以杭州与《烟雨楼盗案》为核心，用探索、人物关系、武学与捕快身份串起一段可以保存的江湖故事。

[在线试玩](https://loser-gif.github.io/jianghu-xing/) · [源码仓库](https://github.com/loser-gif/jianghu-xing)

## 本地运行

需要 Node.js 22.12 或更新版本。

```powershell
cd D:\JHX\jianghu
npm ci
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5173/ 。开发服务器只监听本机。

```powershell
npm test
npm run build
npm run preview
```

生产文件在 `dist/`。采用 Vite 相对资源路径与页面状态导航，部署在仓库子路径下时无须改写前端路由，刷新回到主菜单后可继续存档。

## 已实现的杭州篇

- 6 种出身、选择 2 项天赋、4 种兵器倾向；出身影响属性、银两、装备、初始关系与特殊事件。
- 西湖、悦来客栈、烟雨楼、后巷、旧码头、官府、铁匠铺、青山药庐，共 8 处可游历地点及对应水墨场景。
- 6 名原创 NPC，人物谱、搜索分类、羁绊图、好感与信任、日程、送礼与往事记忆。
- 12 个带条件和分支的探索事件，历史选择会影响后续情报、价格和对话。
- 行囊、武器装备、两件套效果、强化、交易、治疗、6 门武学、修习与条件突破。
- 捕快入职、任务准备、调查、真假线索、追踪、回合战斗、战后救治、搜身取证、非致命拘捕、押送、奖励及资深捕快晋升。
- 战败、放走目标、未完成控制便押送、追缉超时等失败路径；世界继续运行，可重整再追缉。
- 自动存档、3 个手动存档位、上一段江湖备份、JSON 导入导出、损坏存档检查。

## 第一桩案子的走法

1. 创建角色，打开地图前往官府。
2. 拜见陆捕头，进入身份司簿，入职捕快。
3. 打开江湖事，接取《烟雨楼盗案》。购买两条绳索、一条布条并完成准备。
4. 前往烟雨楼调查，再到后巷辨认线索。去东侧水路可抵旧码头；西巷是假线索，会损失时间和气血。
5. 前往旧码头拦下顾红绫。普通攻击无需内力，武学更强，防御可调息，用药占一回合。
6. 完全击败后可先救治、取证，再完成手部、腿部、示警三个控制状态。
7. 安全押送归案，领取 300 两、25 捕快声望、40 官府贡献；在官府申请晋升。

这只是最短路线。先帮助苏婉娘、认识白芷或向剑客学艺，会在任务中留下不同的记录。

## 存档

进度仅存放在浏览器 `localStorage`，键名前缀为 `jianghu.v1.`。自动存档键为 `auto`，手动槽为 `1`、`2`、`3`，新建角色及导入前的备份为 `previous`。不同域名、浏览器或设备的进度相互独立。

首次打开不会自动进入游戏；选择“继续游历”恢复自动存档。战斗回合、敌方气血、任务阶段、道具、关系记忆均保存。清理站点数据会移除存档，迁移设备前请导出 JSON。尚未接入云同步。

## 源码结构

```text
src/
  App.tsx              应用外壳、导航与全局交互
  pages/               拆分的玩法页面、人物详情、战斗与存档界面
  components/UI.tsx    宣纸界面组件、弹窗、进度条、头像
  data/world.ts       地点、NPC、出身、天赋、物品、武学
  data/events.ts      事件条件、选项、效果及剧情
  engine/game.ts      纯状态转换、条件效果、战斗、关系、时间与任务
  engine/storage.ts   存档结构检查和浏览器持久化
  store.ts            Zustand，执行行动并自动保存
  types.ts            游戏数据契约
  styles.css          基础布局与交互样式
  reference.css       按文档原画复刻的竖屏样式
public/reference/     文档原图（Figure 1、8–20）
public/fonts/         本地毛笔字体及 OFL 许可证
tests/game.test.ts    核心流程、失败路径、养成及存档测试
```

添加探索事件时，在 `data/events.ts` 增加配置即可。条件引擎支持 Flag、属性门槛、物品、关系、身份、任务阶段及时辰；效果引擎支持银两、物品、关系、武学、气血、内力与历史标记。UI 不自行修改数值，全部经 `transition()` 执行，便于测试和扩展。
